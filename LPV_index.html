三十秒开始

第一次使用时，macOS 会要求你授权访问所选文件。这是 App Sandbox 的正常行为。

选择图片

在应用中打开文件选择器，选择一张或多张图片；也可以把文件拖到应用图标上。

浏览同目录

打开一张图片后，使用左右方向键即可切换同一文件夹中的其他图片。

调整视图

使用 ⌘ + / ⌘ − 缩放，拖动图片进行平移，按 R 旋转，按 0 恢复默认视图。

查看信息

打开右侧信息面板查看文件、图像和相机信息；需要时可使用 macOS 分享菜单。

常见问题

如果这里没有解决你的问题，请在页面底部提交反馈，并附上系统版本与文件格式。

如何打开图片？

可以在 LPV Viewer 中使用系统文件选择器，也可以把图片拖到应用图标上，或在 Finder 中右键选择“打开方式”。打开一张图片后，同一文件夹里的图片可以用左右方向键浏览。

为什么应用反复请求文件访问权限？

LPV Viewer 使用 macOS 的安全文件访问机制，只读取你主动选择的文件。请通过系统文件选择器重新选择文件或所在文件夹；如果文件位于移动硬盘或网络盘，请确认磁盘仍已连接并且当前账户有访问权限。

支持哪些 RAW 和专业图像格式？

常见 RAW 格式包括 CR2、CR3、NEF、NRW、ARW、SR2、RAF、RW2、ORF、PEF、RWL 和 DNG；同时支持 PSD、PSB、PDD 和 EXR。不同相机型号的 RAW 解码能力可能取决于 macOS 的系统图像组件。

LPV Viewer 会上传我的照片吗？

不会。应用不要求登录，不包含云端上传流程，也不需要网络权限。图片只在你的 Mac 上读取和显示；应用不会编辑或覆盖原始文件。

有哪些快捷键？
  • 左右方向键：切换上一张或下一张图片
  • ⌘ + / ⌘ −：放大或缩小
  • R：顺时针旋转 90°
  • 0：恢复默认缩放与位置
系统要求是什么？

当前版本支持 macOS 13.0 或更高版本，同时提供 Apple Silicon 和 Intel 架构支持。当前支持页对应 LPV Viewer 1.2.3。

隐私与权限

LPV Viewer 的设计原则很简单：你选择什么，应用就读取什么；除此之外不做额外收集。

本地读取

应用只访问你通过 Finder、拖放或系统文件选择器主动选择的图片文件。

没有账号与追踪

不要求注册或登录，不包含广告、分析 SDK 或跨应用跟踪。

不修改原文件

LPV Viewer 用于查看，不会覆盖、移动或上传你的原始照片和图像文件。
